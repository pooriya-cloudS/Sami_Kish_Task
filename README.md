# IoT Device Management API

A production-oriented RESTful API for managing IoT devices and their telemetry data.

This project demonstrates backend engineering best practices including clean architecture, validation, authentication, pagination, aggregation queries, and automated testing.

---

## 📌 Overview

This service provides a backend system for managing:

- Customers
- Devices assigned to customers
- Telemetry data generated by devices

The system is designed with scalability, maintainability, and clean API design in mind.

Key capabilities include:

- RESTful CRUD operations
- Advanced filtering
- Telemetry time-range queries
- Aggregated telemetry statistics
- JWT-based authentication
- Pagination for all list endpoints
- Interactive API documentation
- Automated test coverage
- BDD And TDD principle implementation By Gherkin
---

## ✨ Features

- Customer management
- Device registration and lifecycle management
- Telemetry ingestion endpoint
- Automatic device activity tracking (`last_seen`)
- Filtering devices by type, owner, and status
- Time-range filtering for telemetry queries
- Aggregated statistics (min, max, avg) per metric
- Secure endpoints using JWT authentication
- Paginated responses for scalability
- Swagger / OpenAPI documentation
- Unit and API-level tests

---

## 🏗 Architecture

The application follows a layered and maintainable architecture:

- **Models** — database schema and constraints
- **Serializers** — input validation and response shaping
- **Views** — request handling and orchestration
- **Query Layer** — optimized filtering and aggregation
- **Authentication Layer** — JWT-based access control

### Design Principles

- Separation of concerns
- Explicit and defensive validation
- Predictable API responses
- Minimal coupling between layers
- Scalable query patterns

## 📊 Telemetry Statistics

The system provides aggregated statistics per device and metric:

- Minimum value
- Maximum value
- Average value

Optional time window filtering allows querying telemetry within a specific date range.

Example:

```
GET /api/devices/{id}/telemetry/stats/?start_date=2025-01-01&end_date=2025-01-31
```

## ⚙️ Local Development Setup

### 1. Clone the repository

```bash
git clone https://github.com/pooriya-cloudS/Sami_Kish_Task.git
cd Sami_Kish_Task
```

### 2. Create virtual environment

```bash
python -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file:

```
SECRET_KEY=your_secret_key
DEBUG=True
DATABASE_URL=your_database_url
.
.
.
```

### 5. Apply migrations

```bash
python manage.py migrate
```

### 6. Run development server

```bash
python manage.py runserver
```

Server will be available at:

```
http://127.0.0.1:8000/
```
